# שילוב 45:45 — מצב בדיקה

קוד Lovable נשמר, ונוסף מסלול SPA נפרד עבור GitHub Pages באמצעות `npm run build:pages`. הבנייה הקיימת ל־Lovable נשארה בקובץ vite.config.ts. מסלול Pages משתמש ב־vite.pages.config.ts, בנתיב /4545-app/, בקובץ 404 לשחזור מסלולים ובהפניות Auth מותאמות.

תוקנו סדר Hooks במסך הקבוצה, בחירת המשחק הבא (עדיפות ל־LIVE), רענון נתונים, שגיאות טעינה, הודעות הצ׳אט האחרונות, תזמון וידג׳ט לפי יום, שם משתמש תפוס, ונתיב הגישה ל־Admin המלא. נוספה בדיקה שמונעת מפתח service-role גם אם הוא JWT ישן להגיע לדפדפן. פרסום ידיעה ב־React Admin עובר דרך שלב approved; RLS בשרת נשאר מקור הסמכות.

קוד Edge Function הוחלף בעותק שהורד מהפונקציה הפרוסה בתחילת העבודה, הכולל בדיקת הרשאת שרת וסנכרון בשלבים. שם הפונקציה בייצור הוא quick-service למרות כותרת sync-football; אין לפרוס אוטומטית שם חדש או להחליף פונקציה בייצור. לא בוצע סנכרון.

## אימות בפועל

- שש בדיקות Node עברו: נתיבי Auth, הפצת שגיאות Supabase, סדר משחקים, תאריכי override בווידג׳ט, סינון מפתחות שרת וטיפול בתשובות מקושרות של Supabase.
- קריאת information_schema בייצור הראתה ש־content_prefs, notification_prefs ו־onboarding_completed חסרים בפרופילים; club_standings, club_trophies ו־club_change_history חסרות.
- get_public_profiles, username_available, change_favorite_club, match_events ו־widget_schedule נמצאו.
- לאחר שינוי הרשאות הסביבה, התקנת התלויות הושלמה. `pnpm run build:pages`, `pnpm run build` ו־`pnpm exec tsc --noEmit` עברו. קובץ pnpm-lock.yaml שומר את גרסאות התלויות שהותקנו, וה־CI משתמש בו.
- בדפדפן המקומי נבדקו מסך ההתחברות, פתיחת טופס ההרשמה והפניה של מסלול משחקים להתחברות ללא משתמש; לא נמצאו שגיאות דפדפן. לא בוצעה הרשמה או שמירת נתונים בייצור, ולא אומתו פעולות עם חשבון מחובר או הרשאות צוות.
- הבחירה האחרונה של המשתמש היא לשמור הכול מקומית בלבד. לא נוצרו ענף או PR, ולא בוצעו שינויי Supabase או פריסה.

## לפני פרסום

1. להריץ בדיקות ובנייה בענף נפרד ב־GitHub Actions. טיוטת PR אינה פורסת ייצור.
2. לסקור ולאשר בנפרד את supabase/releases/20261014_web_support.sql: שדות חדשים וטבלאות תמיכה עם RLS, ללא איפוס נתונים או החלפת פונקציות קיימות. הסקריפט לא הורץ.
3. לאמת מדיניות RLS עם חשבון רגיל וחשבון צוות ולבדוק Auth, משחק, צ׳אט, אישור חדשות ו־Widget על סביבת בדיקה. עצם קיום הטבלאות אינו בדיקת הרשאות.
4. לוודא כתובות Auth המותרות ב־Supabase כוללות /4545-app/ ו־/4545-app/reset-password. לא לשנות הגדרות ללא אישור.
5. לקבל אישור לפני מיזוג ל־main ופריסת האתר. אין שינויים בנתוני הייצור עד לאישור.

## מגבלות שנותרו

אין כאן שירות Push פעיל או Widget מערכת iOS/Android; הקוד מכיל העדפות התראות ווידג׳ט בתוך האתר. נתוני דירוג ותארים יופיעו רק לאחר הזנתם, ולא הומצאו נתונים. העדכון אינו טוען שכל פונקציות המוצר הושלמו.
